# Инна, это всё для тебя ♡

Анимированная открытка для бабули Инны, с любовью от Егора.

## Открыть

[Сайт на GitHub Pages](https://sallyvally.github.io/inna-birthday/)

Полноэкранная история для телефона: раскрывающийся конверт, фотография, личное письмо, букет цветов, свеча и праздничный финал. Цветы распускаются от касания. После свечи появляется поздравление с конфетти. Открытку можно повторить.

Музыка — небольшая оригинальная аранжировка колокольчиков через Web Audio; включается только вручную. Запрос микрофона не требуется.

## Разработка

Статический HTML, CSS и JavaScript. Внешних библиотек, шрифтов, аналитики и сторонних запросов нет. Фотография предоставлена владельцем открытки.

Запуск локально: `python -m http.server 4173`, затем открыть `http://localhost:4173/`.

Публикация через GitHub Pages из корня ветки `main`. Файл `.nojekyll` отключает обработку Jekyll. Сборка не нужна.

Навигация: кнопки, горизонтальный свайп на телефоне, стрелки клавиатуры. Учтены безопасные области экрана, компактные телефоны и настройка сокращённой анимации. Длинное письмо на маленьком экране прокручивается внутри листа.
